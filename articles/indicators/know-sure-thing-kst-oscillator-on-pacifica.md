What is Know Sure Thing (KST)?

Know Sure Thing (KST) is a trend oscillator that helps traders find reversals and confirm trends.

This indicator was developed by Martin Prang and is based on the idea that prices move in waves with different cycles, and they can be analyzed simultaneously.

👉 The main idea of ​​KST:

If KST rises and is above zero → the trend is up.

If KST falls and is below zero → the trend is down.

KST line intersections provide entry and exit signals.

### How to interpret KST?

1.**Zero line crossover**

If KST crosses 0 upwards → buy signal.

If KST crosses 0 downwards → sell signal.

This is the main trend signal!

1. **Signal line crossover**

KST has an additional signal line (usually a smoothed KST).

If KST crosses the signal line upwards → bullish signal (long).

If KST crosses the signal line downwards → bearish signal (short).

This signal is more sensitive and suitable for entering the market!

1. **Divergence**

If the price makes a new high, and KST is below the previous peak → a downward reversal is possible.

If the price makes a new low, and KST is above the previous bottom → a upward reversal is possible.

> **Divergences on KST work the same way as in MACD and RSI.**

**Pros and cons of KST**

**Pros:**

✔ Good trend detection.

✔ Filters out false signals.

✔ Works in combination with other indicators.

**Cons:**

✖ Lagging compared to RSI.

✖ May give false signals on small timeframes.

Tip: Use KST on H1, H4 and daily charts for accurate signals.

> **Know Sure Thing (KST) is a great trend indicator that helps find**reversals and confirm trends.**

✔ Crossing 0 is the main trend signal.

✔ Crossing the signal line is a good entry point.

✔ Divergence of KST and price is a powerful reversal signal.

KST gives the best results in combination with MACD, RSI and moving averages!
